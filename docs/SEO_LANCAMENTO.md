# SEO de lançamento — Educalizando

## O que já está publicado no código

- Sitemap dinâmico: `https://www.educalizando.com.br/sitemap.xml`
- Regras de rastreamento: `https://www.educalizando.com.br/robots.txt`
- Feed de produtos finais pagos: `https://www.educalizando.com.br/feed/google.xml`
- Dados estruturados de organização, produto, oferta e breadcrumb.
- URL canônica única para cada produto: `/produto/{slug}`.

## Ações externas obrigatórias

1. Verificar a propriedade `https://www.educalizando.com.br` no Google Search Console.
2. Enviar o sitemap e inspecionar a página inicial, uma categoria, uma loja e um produto publicado.
3. Criar a conta no Google Merchant Center e cadastrar o feed `https://www.educalizando.com.br/feed/google.xml` como fonte programada diária.
4. Validar uma página de produto no Rich Results Test do Google e corrigir qualquer aviso de preço, imagem ou disponibilidade.
5. Garantir no provedor de hospedagem as variáveis reais do Supabase e `NEXT_PUBLIC_SITE_URL=https://www.educalizando.com.br`.

## Rotina semanal

- Conferir no Search Console consultas, páginas indexadas, erros de cobertura e Core Web Vitals.
- Criar conteúdo original baseado nas buscas reais dos educadores.
- Revisar produtos sem capa, descrição, categoria, nível de ensino, tags ou tema.
- Priorizar páginas e materiais que recebem impressões, mas têm baixo clique.

## Padrão de cadastro para criadores

Cada material publicado deve ter título claro, descrição própria, capa legível, faixa ou nível de ensino, categoria, até dez tags de busca e, quando aplicável, disciplina, BNCC e tema do calendário. Não publicar textos em massa sem revisão pedagógica.
